# Battle Dice web UI

Web UI for battle dice.

## Tech

This UI uses

- React
- Typescript
- Camera API
- QR codes
- Websockets (Socket.IO)
- Mantine

## Usage

I have it hosted, but I need to buy a pretty name for it. For now, clone the repo, run `npm install` and `npm run start` to get it running locally.

You'll need to get a server running as well. Look below for the server repo link.

## What's what

Add your name, create or join a room, invite others.
This app allows you to roll opposing dice against your friends (or enemies). Why settle disputes with words or swords, when you can roll dice against others?
